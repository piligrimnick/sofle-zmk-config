# Sofle Choc V3.5 — ZMK config

Базовая прошивка для двух половин Sofle Choc V3.5 с контроллерами
`nice!nano v2` или совместимыми nRF52840-клонами в Pro Micro-формате.

Включены матрица клавиш, Bluetooth и все 29 in-switch RGB-светодиодов на каждой
половине. Нижнего underglow у этой PCB нет и прошивка его не адресует. Дисплеи
и энкодеры пока выключены. ZMK закреплён на стабильном релизе `v0.3`.

## Сборка через GitHub Actions

Готовые и проверенные локальной сборкой файлы уже лежат в `firmware/`:

- `firmware/sofle-left.uf2`;
- `firmware/sofle-right.uf2`;
- `firmware/settings-reset.uf2`.

Папка `firmware/` исключена из Git: бинарники можно сразу прошивать локально,
а после каждого push GitHub Actions заново собирает их из исходников.

Для последующих сборок через GitHub:

1. Создайте пустой репозиторий на GitHub и добавьте его как `origin`.
2. Закоммитьте и отправьте содержимое этой папки.
3. Откройте вкладку **Actions**, дождитесь успешной задачи **Build ZMK firmware**.
4. Скачайте и распакуйте artifact `firmware`.

В архиве будут:

- `sofle-left.uf2` — левая, центральная половина;
- `sofle-right.uf2` — правая, периферийная половина;
- `settings-reset.uf2` — только для очистки старых BLE-привязок.

## Первая прошивка

1. Выключите обе половины. Не подключайте и не отключайте TRRS при включённом
   питании. Для беспроводной сборки TRRS вообще не нужен.
2. Подключите правую половину по USB, дважды быстро нажмите Reset. Появится
   USB-диск `NICENANO`; скопируйте на него `sofle-right.uf2`.
3. Отключите правую половину и включите её от батареи.
4. Аналогично прошейте левую половину файлом `sofle-left.uf2`.
5. На компьютере найдите Bluetooth-устройство `Sofle` и подключитесь к нему.

UF2-диск исчезает после копирования — это нормальная перезагрузка контроллера.
Не прошивайте левый файл в правую половину и наоборот.

Если половины раньше использовались с другой прошивкой и не связываются:

1. Прошейте `settings-reset.uf2` по очереди в обе половины.
2. Снова прошейте `sofle-right.uf2` в правую, затем `sofle-left.uf2` в левую.
3. Удалите старое Bluetooth-устройство `Sofle` на компьютере и подключите заново.

## Базовая раскладка

Это штатная четырёхслойная раскладка ZMK для Sofle:

- нижняя левая клавиша слоя включает `LOWER`;
- нижняя правая клавиша слоя включает `RAISE`;
- одновременное удержание `LOWER` + `RAISE` включает `ADJUST`;
- на `RAISE` верхний ряд содержит очистку и выбор пяти Bluetooth-профилей.

Раскладка редактируется в `config/sofle.keymap`, опции — в
`config/sofle.conf`, цели сборки — в `build.yaml`.

## Аппаратные допущения

Конфигурация рассчитана на стандартную электрическую распиновку Sofle и
`nice!nano v2`. Для оригинального `nice!nano v1`, Frood/Pro Micro (проводная
сборка), встроенного контроллера либо иной ревизии нужно изменить `board`.

У V3.5 от 42.Keebs RGB подключён не так, как в стандартной Sofle. Дополнительный
shield `sofle_choc_v35_rgb` задаёт GPIO D4/P0.22 и ровно 29 светодиодов на
каждую половину (58 всего). В терминологии ZMK эта подсистема всё равно
называется `RGB_UNDERGLOW`, хотя физически это только подсветка клавиш. Это
соответствует [руководству ZMK по RGB lighting](https://zmk.dev/docs/hardware-integration/lighting/underglow):
адресная цепочка работает через LED strip на `SPI3`, а аппаратная настройка
nice!nano находится в board-specific overlay дополнительного shield.

При старте включается статический свет; максимум ограничен 30%. Яркость
проходит от 0 до максимума за 15 нажатий (примерно по 2% выходной яркости),
чтобы не перегружать маленькую батарею или USB-питание во время проверки.
Управление RGB находится на слое `ADJUST`.

## Световая индикация

Поверх обычных эффектов добавлена служебная индикация. Она не меняет
сохранённые цвет, яркость, эффект или состояние RGB:

- при включении каждая половина плавно зажигает все свои светодиоды белым до
  10% за 3 секунды, затем плавно гасит их ещё 3 секунды и возвращает обычный
  эффект;
- при подключении компьютера по Bluetooth левая половина непрерывно горит
  синим 4 секунды;
- пока выбран пустой Bluetooth-профиль и клавиатура доступна для сопряжения,
  левая половина часто мигает синим; после подключения мигание прекращается.

Режим сопряжения включается штатными командами на слоях `RAISE`/`ADJUST`:
выберите свободный профиль `BT1`–`BT5` либо очистите текущий через `BTCLR`.
Bluetooth-индикация есть только на левой (центральной) половине: правая
половина по архитектуре ZMK не знает о соединении клавиатуры с компьютером.

Для безопасной проверки удерживайте `RAISE` на правом thumb-кластере и нажмите
верхнюю клавишу `5` (`BT5`). Если профиль свободен, частое синее мигание
начнётся сразу. Если профиль занят, оставив `RAISE` зажатым, нажмите крайнюю
верхнюю левую клавишу с базовым символом `` ` `` (`BTCLR`), чтобы очистить
только выбранный `BT5`. Для возврата к основному профилю обычно достаточно
`RAISE` + `1` (`BT1`).

## Память подсветки для Bluetooth-профилей

У каждого из пяти профилей `BT1`–`BT5` теперь своя независимая ячейка RGB. В
ней сохраняются:

- включена ли подсветка;
- цвет (hue и saturation);
- яркость;
- эффект;
- скорость эффекта.

Чтобы настроить ячейку, сначала выберите нужный профиль через `RAISE` +
`1`…`5`, затем меняйте RGB обычными командами на слое `ADJUST`. При следующем
выборе этого BT-профиля его подсветка восстановится автоматически. Левая
половина передаёт правой полное состояние активной ячейки, в том числе если
правая была выключена во время предыдущих изменений.

После первой установки новой прошивки существующая глобальная настройка RGB
копируется во все пять ячеек. Bluetooth-привязки при этом не стираются и
`settings-reset.uf2` прошивать не нужно. Как и штатные настройки ZMK, изменения
записываются во flash после 60-секундной паузы; прежде чем сразу выключать
питание после настройки цвета, лучше подождать минуту.

## Заряд обеих половин на macOS

Левая половина получает заряд правой по split-BLE и публикует оба значения как
два стандартных BLE Battery Service. Обычный интерфейс macOS чаще показывает
только основной аккумулятор, поэтому для строки меню рекомендуется
[ZMK Battery Bar](https://github.com/itouuuuuuuuu/zmk-battery-bar) (macOS 14+):

```shell
brew install --cask itouuuuuuuuu/tap/zmk-battery-bar
```

При первом запуске разрешите приложению Bluetooth, нажмите **Add Keyboard** и
выберите `Sofle`. Метки половин можно заменить с `C`/`P` на `L`/`R` в настройках
приложения. Уровни обновляются примерно раз в минуту и являются оценкой по
напряжению аккумулятора, а не измерением отдельным fuel-gauge контроллером.

Прошивка каждой половины сглаживает показания медианой трёх последних замеров.
Первое значение после включения появляется сразу, одиночный скачок от нагрузки
или зарядки отбрасывается, а настоящее изменение подтверждается следующим
минутным замером. Для работы фильтра нужно прошить обе половины.
